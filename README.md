# Mercer Case Prototype

An interactive investigation / case-file prototype built as a browser-based narrative experience.

The interface presents a reopened case through structured evidence, people records, notes and media rather than through a conventional linear story. The goal is to make the user investigate the narrative by navigating the archive itself.

## Experience design

- Case-file based storytelling
- Separate views for files, people and notebook content
- Evidence imagery and media inspection
- Bilingual EN / FR interface
- Responsive browser experience
- Narrative progression through discovery rather than chapter-by-chapter exposition

## Implementation

The prototype is intentionally lightweight and runs as a static web experience using HTML, CSS and JavaScript, with visual assets loaded from a dedicated asset endpoint.

## Why the project matters

It demonstrates how fiction, UX and product design can be combined into an interactive narrative format. The work spans world-building, information architecture, interface design and implementation, making it relevant both as a creative-writing proof point and as an example of rapid digital prototyping.
